# Changelog

All notable changes to `serixa/auth-ui` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-07-22

### Added

- Initial release of the official SERIXA Auth UI package (UI only).
- Layout: `AuthLayout`, `AuthCard`, `AuthHeader`, `AuthFooter`, `AuthAside`, `AuthIllustration`.
- Page cards: Login, Register, ForgotPassword, ResetPassword, VerifyEmail, TwoFactor, MagicLink.
- Components: BrandLogo, AuthDivider, SocialLoginButtons, RememberMeCheckbox, PasswordStrength, PasswordRequirements, AuthLink, AuthAlert.
- `AuthTheme` / `auth.*` keys stacked with FormsTheme + AdminTheme.
- Examples for login, register, forgot/reset password, two-factor, magic-link.
- Documentation in `docs/auth-ui.md`.
