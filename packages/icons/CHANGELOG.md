# Changelog

## [0.1.0] — 2026-07-22

### Added
- Official `serixa/icons` package
- `Icon` widget with size, color, a11y, stroke, filled/outlined API
- Icon packs: Heroicons (default), Feather, Lucide via `IconPackInterface`
- `IconRegistry` for pack registration and resolution
- Shared outline catalog (100+ icons)
- Examples, documentation, PHPUnit suite
