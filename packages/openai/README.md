# serixa/openai

Language model contracts (`LanguageModel`) plus `OpenAiLanguageModel`, `EchoLanguageModel`, and an `OpenAiClient` port (`FakeOpenAiClient` for tests).

Other LLM adapters (`gemini`, `anthropic`, `deepseek`, `ollama`) implement the same contract.

See [docs/openai.md](docs/openai.md).
