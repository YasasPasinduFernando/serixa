# Changelog

All notable changes to `serixa/calendar` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-07-22

### Added

- Initial release of the official SERIXA Calendar package (UI only).
- Widgets: Calendar, MiniCalendar, MonthView, WeekView, DayView, AgendaView, TimelineCalendar, ResourceCalendar, Scheduler, DatePicker, DateRangePicker, TimePicker, DateTimePicker, EventCard, EventBadge, EventPopover, EventLegend, CalendarToolbar.
- Event API: `Event`, `EventCollection`, `EventNormalizer` — arrays, Traversable, JSON, generators.
- `CalendarTheme` decorator and `calendar.*` theme keys.
- SSR semantic grids/lists; progressive enhancement via `assets/calendar.js` and `CalendarRuntime`.
- Examples: booking, CRM schedule, admin planner, team calendar, project timeline, personal agenda.
- Documentation in `docs/calendar.md`.
