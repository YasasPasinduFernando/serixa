# Namespace policy

## Canonical namespace

All code must use:

```text
Serixa\
```

PSR-4 mapping (Composer):

```json
"Serixa\\": "src/"
```

## Product vs package vs namespace

| Layer | Value |
|-------|--------|
| Product | SERIXA |
| Composer | `serixa/framework` |
| PHP namespace | `Serixa\` |
