# SERIXA v1.0.0 — Release notes (draft)

## Highlights

- Offline Theme Compiler (`Serixa\Styling`) → `/assets/serixa.css`
- Layout width ownership (`fill()` / `Expanded`) — no generic `w-full` fights
- Conflict-aware `ClassMerger`
- Official packages: icons, admin, forms, auth-ui, charts, calendar, devtools, cli
- Documentation website + starters (blog, admin) + validation apps
- Stabilization pass: docs sync, semantic tokens (border/opacity/z-index/breakpoint/transition), null profilers, release docs
